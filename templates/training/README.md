# Training Metadata Templates

`mm_train train` reads `dataset_parameter.json` and `data_stats.json` from the
directory passed to `--result_dir`. It generates `training_config.json` in that
directory; do not create that file manually.

## Recommended setup

1. Copy `dataset_parameter.json` into the intended result directory.
2. Replace every `CHANGE_ME_...` value and update `numTraining`.
3. Generate `data_stats.json` directly from the NIfTI headers:

   ```bash
   mm_train stats -d /absolute/path/to/dataset -o /absolute/path/to/result_dir
   ```

4. Start training with the same result directory:

   ```bash
   mm_train train -d /absolute/path/to/dataset -o /absolute/path/to/result_dir --yes
   ```

The dataset directory must contain `imagesTr` and `labelsTr`. For one input
channel, images must be named `<case>_0000.nii.gz` and labels must be named
`<case>.nii.gz`.

## `dataset_parameter.json`

- `description`: Human-readable dataset purpose.
- `labels`: Map each class name to the integer stored in the label NIfTI. Keep
  `background` as `0`. Add or remove foreground entries as needed.
- `name`: Short dataset name used in model metadata.
- `numTraining`: Number of paired cases in `imagesTr` and `labelsTr`.
- `reference`: Dataset publication, URL, internal identifier, or an empty string.
- `release`: Dataset or metadata version.
- `channel_names`: Map zero-based channel numbers to modality names. The keys
  must match filename suffixes such as `_0000` and `_0001`.
- `file_ending`: Keep `.nii.gz` for compressed NIfTI input.

## `data_stats.json`

Normally, do not edit this file. The `stats` command writes one `spacings` row
and one `sizes` row per training case. Training uses the median spacing, rounded
to the nearest 0.1 mm, unless `--spacing X Y Z` overrides it.

The included file is only a structural example. If edited manually:

- `dataset_dir` must be the absolute dataset path.
- `num_cases` must match the number of rows in both arrays.
- Each `spacings` row is `[x_mm, y_mm, z_mm]` for one image.
- Each `sizes` row is `[x_voxels, y_voxels, z_voxels]` for the same image.
